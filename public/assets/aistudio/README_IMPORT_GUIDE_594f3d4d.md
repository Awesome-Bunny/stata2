# КАК ИМПОРТИРОВАТЬ ЭТОТ ПАКЕТ В GOOGLE AI STUDIO (ЗА 1 МИНУТУ)

В этом архиве собраны все файлы для переноса вашего тренажёра по статистике в **Google AI Studio (`aistudio.google.com`)**, **VS Code / Cursor** или для запуска прямо на компьютере.

## Состав архива:
1. **`SYSTEM_PROMPT_AI_STUDIO.md`** — полный системный промпт со всеми правилами расчёта, тестовыми заданиями (№10–13), изучением степеней свободы ($df = k - 3$ и $df = (r-1)(c-1)$) и инструкциями по интерактивному словарю А. Д. Наследова.
2. **`NASLEDOV_KNOWLEDGE_BASE.md`** — конспект-выжимка терминов, формул и таблиц из учебника А. Д. Наследова + все ключи Варианта 1 (Марина Жукурмало) и Варианта 3.
3. **Многофайловая версия веб-приложения (для разработки):**
   - `index.html` — главная страница интерфейса;
   - `styles.css` — таблица стилей;
   - `data.js` — база терминов по Наследову, таблица $\chi^2$, пошаговые задания Варианта 1 и 3, тренажёр степеней свободы и банк тестов;
   - `app.js` — логика проверки шагов, кликабельных терминов-чипов и калькулятора степеней свободы.
4. **`stats_exam_trainer_standalone.html`** — автономная однофайловая версия тренажёра (всё в одном файле), которую можно сразу открыть в любом браузере на телефоне или ноутбуке.

## Пошаговая инструкция для Google AI Studio:
1. Откройте [aistudio.google.com](https://aistudio.google.com) и нажмите **Create Prompt**.
2. Скопируйте содержимое файла **`SYSTEM_PROMPT_AI_STUDIO.md`** и вставьте его в верхнее поле **System Instructions**.
3. Нажмите кнопку **`+`** в строке чата и прикрепите файлы из этой папки (`NASLEDOV_KNOWLEDGE_BASE.md`, `data.js`, `app.js`, `index.html`, `styles.css`, а также при желании PDF самого учебника Наследова).
4. Нажмите **Save** в правом верхнем углу — ваш проект с полной памятью готов к работе!
