**Точный текст с бланка:**
В таблице представлены средние значения зарплат в некотором регионе за 7 лет. Известно, что динамика з/п описывается *параболическим уравнением тренда*, для которого рассчитаны коэффициенты a, b, c. ***Напишите уравнение для прогноза средней зарплаты в этом регионе в 2026 году? (4)***

| Год | Средняя зарплата | Коэффициенты модели |
| :--- | :--- | :--- |
| 2018 | 40676 | $a = 46266$ |
| 2019 | 43695 | $b = 2274$ |
| 2020 | 48715 | $c = 108$ |
| 2021 | 54321 | |
| 2022 | 60225 | |
| 2023 | 76611 | |

* **Алгоритм решения по ключу Степанова:**
  1. Параболическое уравнение тренда имеет вид: $\hat{y} = a + b \cdot t + c \cdot t^2$.
  2. Смотрим на количество фактически представленных в таблице годов: их **6 (чётное количество: 2018–2023 гг.)**.
  3. Середина чётного ряда — два центральных года: **2020** и **2021**. Значит, $2020\text{ г.} = -1$, а $2021\text{ г.} = +1$. При чётном ряде шаг вниз составляет $+2$ за каждый год:
     * $2020 \to t = -1$
     * $2021 \to t = +1$
     * $2022 \to t = +3$
     * $2023 \to t = +5$
     * $2024 \to t = +7$
     * $2025 \to t = +9$
     * **$2026 \to t = +11$** (отсюда $t^2 = 11^2 = 121$).
     *(Правило для нечётного ряда: если бы количество лет было нечётным и имело одну чёткую середину, например 2020 год, то середина обозначалась бы за $0$, а шаг вниз шёл бы по $+1$).*

     $$\hat{y}_{2026} = 46\,266 + 2274 \cdot 11 + 108 \cdot 11^2 = 46\,266 + 25\,014 + 13\,068 = \mathbf{84\,348}$$
